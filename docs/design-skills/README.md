# YAAG Studio — UI/UX design reference pack

A small, locally saved set of practical design notes used to shape the YAAG Year-at-a-Glance builder. These are original summaries and application checklists—not copies of the source publications. The reference links below point to the maintained originals.

## Included skills

- `01-product-ux.md` — predictable controls, user agency, status, error prevention, and progressive disclosure.
- `02-accessibility.md` — WCAG 2.2 AA-informed interface and print legibility checklist.
- `03-visual-systems.md` — hierarchy, tokens, typography, palettes, and consistent components.
- `04-responsive-print.md` — screen-to-paper behavior, page sizing, calendar density, and print QA.
- `05-content-and-privacy.md` — clear labels, local-first settings, portable configuration, and safe personalization.

## How these were selected and used

There is no single authoritative package called “all top UI/UX design skills.” I selected a focused set of primary references: Nielsen Norman Group's usability heuristics, the W3C WCAG 2.2 Recommendation, Apple's Human Interface Guidelines, Google's Material 3 design system, and Damir Sokolovsky's Unslop process. I reviewed the public guidance, distilled relevant parts into the checklists here, and applied the Unslop audit/direction/refinement workflow. See `../UNSLOP_ADAPTATION.md` for CC BY 4.0 attribution; this project does not include the original skill source or its image assets.

The tool is intentionally self-contained: no third-party font/CDN dependency, no remote service, and no calendar data sent anywhere. The builder applies the notes through clear grouped settings, native form controls, a persistent live preview, visible focus states, multiple palette/layout presets, exportable setup JSON, and print-specific page rules.

## Scope note

This reference pack is a practical design aid, not a certification or legal accessibility audit. Validate the generated printout on the intended printer and paper stock; printer margins and browser print dialogs can affect output.
